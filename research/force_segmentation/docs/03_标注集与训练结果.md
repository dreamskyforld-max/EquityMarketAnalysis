`seg/labels.py`（唯一真相源）：**5 只股票 × 19 个交易日 = 237 个窗口**

| 股票 | 标注日 | 窗口数 | 特征 |

## 3. 训练出的权重

```
[SSE 1.0, 每段 7.32, 方向翻转 29.38, 过短 19.85, 幅度不足 35.74, 低效 5.03]
```

解读：
- **幅度不足（35.7）+ 方向翻转（29.4）主导** → "没分量的一段不单独成窗"、"确实换了力量才切"；
- 每段固定代价仅 7.3 → 粒度由"有没有分量"决定，不是硬限段数；
- 低效仅 5.0 → 低效不参与切分，只作标记（与人工判断一致）。

## 4. 关键单次验证

- **10-29 13:17-13:31**（研究起点）：
  现行口径淹没在 `11:04-15:28`（205min）；
  V3（细粒度）→ `13:17-13:33 下跌 -0.523%，z=-9.2`；
  V3（含效应量合并）→ `13:05-13:27 -0.418%`；
  用户最终标注（10-28 修订）→ `11:26-13:16 / 13:17-13:32 / 13:33-13:55`。
- **V 型反转**（10-27 ⑦⑧）：并成一段会让 SSE 爆炸 → 模型自动保留两侧，无需特殊规则。
- **跨午休**（10-21 `11:07-13:57`、10-28 `11:26-13:16`、10-18 `11:43-13:54`）：
  模型已能产出（候选集去掉午休切点后）。
