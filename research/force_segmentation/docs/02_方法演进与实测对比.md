# 02 方法演进与实测对比

四代方法，全部在真实数据上做过对照（HK.00700 为主，后扩到 5 只票）。

## V0：现行生产口径 —— ZigZag + L1.5 单刀加速

`trend_segmenter.layer1_segments`（平滑 → 极值 → 折返 ≥ 0.30% 确认拐点 → 锚回原始极值）
+ `split_big_accel`（每段最多一刀，把「缓→急」的大加速切出）。

**实测问题（2026-10-29）**

| 问题 | 表现 |
|---|---|
| 段太长 | `11:04–15:28` 一个 205 分钟下跌段，ER 0.11、σfit/σnoise 2.09 |
| 不认停顿 | 三天里**横盘段 = 0** 个 |
| 段内藏 V | `09:58-10:30 下跌` 里完整装着一个 V；`09:30-09:45 下跌` 同理 |
| 加速只切一刀 | `split_big_accel` 每段最多一刀，13:17 的加速让位给尾盘急跌 |

## V1：分段线性 + 最优划分（MDL）+ 自底向上合并

- 每段做线性拟合，代价 = ΣSSE + β·K，β 网格 + MDL 选段数，DP 求全局最优；
- 合并：同向且斜率差不显著 / 幅度不足 → 并；短停顿 → 并入相邻；
- **禁止跨交易时段合并**（上午末段与下午首段在列表里相邻，不拦住会并成跨午休段，
  下游按段分组时整段丢弃 → 10-28 出现 52 分钟覆盖空洞）。

## V3：V1 + 三项修正 + 合并规则 R1/R2/R3

- **A 结构切分**：段内振幅 ≥ 效应量且 ≥ 2×\|首尾涨跌\| → 在段内极值处切开（解决"横盘藏 V"）。
- **B 标记**：低效 / 波动。
  ⚠ 低效用**段内方向性最大位移**，不能用首尾净位移：
  10-29 `13:00-13:30` 峰谷 -2.6 元、首尾只差 -1.4 元，按净位移会被误判低效 → 触发 R3 级联，
  下午被并成 147 分钟一段。
- **C 极值锚定**：边界从「斜率变化点」锚回 ±3 分钟窗内原始价格极值
  （下跌段起点锚峰 / 上涨段起点锚谷 / 同向加速锚台阶顶）。
  这一步直接解决了 13:17-13:31：锚定后得到 `13:07-13:30 下跌 -0.522%`，边界正好落在峰和真实低点上。
- **R1** 相邻横盘合并 / **R2** 短横盘并入相邻 / **R3** 相邻低效合并（限原始窗口，防级联）。

## V4：带权代价 + DP 全局最优（训练模型，当前最好）

`Cost(S) = w·φ(S)`，`φ = [ΣSSE, K, 方向翻转数, Σ过短hinge, Σ幅度不足hinge, Σ低效hinge]`，
DP 求给定权重下的全局最优，权重在人工标注集上训练。

**为什么不继续写规则（关键实测）**

1. 规则堆是**局部 if-else**，看不到上下文；而标注里的判断依赖上下文。三组硬矛盾：

   | 窗口 | 标签 | 时长 | 涨跌% | ER | \|z\| |
   |---|---|---|---|---|---|
   | 10-26 10:09-10:13 | 保留→后改为合并 | 5min | +0.260 | 0.71 | 2.8 |
   | 10-28 11:13-11:17 | 合并 | 5min | -0.257 | 1.00 | 4.1 |
   | 10-27 10:40-10:50 | 保留（V 型反转） | 11min | +0.414 | 0.67 | **11.6** |
   | 10-29 10:06-10:16 | 合并 | 11min | +0.368 | 0.64 | **5.8** |

   同样形态、相反标签 → **任何"窗口局部特征 + 阈值"的规则族都拟合不上**。

2. 每次新增标注都是在打补丁：修好一天就破坏另一天（低效链式合并在 10-28 要链、在 10-26 不能链）。

3. DP 天然带上下文（一段的去留取决于前后段怎么切），且权重可训练。

**候选边界的选择（踩过的坑）**

| 候选集 | TRAIN F1 | 说明 |
|---|---|---|
| 全部局部极值 | 0.345 | 段数对了但**边界位置**与人工标注不同源 |
| v3 超切边界 | 0.809 | 与标注同源，最高只能与规则堆打平 |
| v3 ∪ 全部极值 | 0.345 | 同上，模型在别处乱切 |
| **v3 ∪ 标注中出现过的边界（定向增补）** | **0.917** | 够得到人工新增的边界（如 10-28 的 13:16/13:32/13:55），又不乱切 |

⚠ 定向增补 = 「教师强制」：训练/评估时把标注边界放进候选集，用来回答
"是否存在一组统一权重能解释这些标注"。**生产推断时只能用 v3 边界**，
此时模型上限 ≈ v3 + 跨午休能力 —— 这是当前最大的待解决问题。

**训练器踩坑**

- 结构化感知机**发散**：未归一 → 在「1 段 ↔ 55 段」之间来回震荡；
  归一到 σ²·n 又会把拟合项压到 ~0.01。正确归一是 SSE/σ²（~O(n)）、hinge/n。
- 最终改用**随机搜索 + 坐标下降**（6 维，损失面非凸有平台，直接搜更稳）。
