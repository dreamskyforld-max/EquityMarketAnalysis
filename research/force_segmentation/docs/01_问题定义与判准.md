# 01 问题定义与判准

## 1. 要解决的问题

给定一只票某一天的分钟价格序列 `p[0..n-1]`，把它切成若干**连续覆盖、无空洞无重叠**的窗口，
每个窗口 = 一次「力量的持续施加」（多空博弈的一个回合）。

窗口是 `force_dynamics` 的一切指标的输入：λ（边际效率）、LQ（对手盘厚度）、keep（冲击留存）
都在窗口内计算（`force_dynamics._close`）。**窗口切错，后面的指标全错。**

## 2. 「合理窗口」的判准（研究的起点）

| 判准 | 含义 | 可量化指标 |
|---|---|---|
| 段内同质 | 段内是同一方向、同一速率的推动 | σfit/σnoise（段内线性拟合残差 ÷ 分钟噪声，越→1 越好）、ER（路径效率 = \|净位移\|÷路径长度） |
| 段间异质 | 边界处方向或速率发生**显著**变化 | 相邻段斜率差的 z 值 |
| 边界可定位 | 边界应在价格摆动的**极值**上，不是拟合断点 | 与人工标注的边界偏差 |
| 前缀稳定 | 盘中每分钟重算，已收口段不得重排 | 漂移处数 / 15 次测试 |
| 参数自标定 | 不依赖绝对百分比，跨票跨波动率可用 | 留一股票 CV |
| 效应量 | 切出来的段「有分量」，不是噪声级抖动 | 段内振幅 ≥ 效应量门槛 |

## 3. 三类结构（人工标注中反复出现）

1. **趋势推进**：一段持续的单边推动（涨或跌），ER 高。
2. **停顿**：平台/震荡，无方向（`win_side=0`，前端不画柱）。
3. **V 型反转**：快速反向，两侧各自 ER 高、\|z\| 大 → **两侧都应保留为独立窗口**。

现在的生产口径（ZigZag）只能识别第 1 类的**方向反转**，第 2、3 类都会出错：
停顿被并入相邻趋势段，V 型的某一侧被吞掉。

## 4. 数据事实（HK.00700，2026-10-26~29 + 另外 4 只票）

- 分钟噪声 σ ≈ 0.47~0.87 ‰/min（对数价格二阶差分估计）。
- **午休跳变只有 0.66~1.77σ**（10-26: 1.44σ / 10-27: 0.66σ / 10-28: 1.77σ / 10-29: 1.14σ）
  → 午休不构成边界，连续走势应跨午休成窗（用户 2026-10-29 确认）。
- 价格最小变动 0.2 元、噪声 0.34 元左右 → 3~5 分钟内的"方向"基本是噪声，
  因此**最短段长**必须显式约束（研究中用 MS=3 硬约束 + 候选边界控制粒度）。

## 5. 不做什么

- 不改 `force_dynamics._close` 的指标口径（λ / LQ / keep 定义不变）——只换窗口。
- 不做预测（历史结论：OFI、方向回测均无预测力，见既有文档）。
- 不引入新的数据源（分钟价格来自 `trend_snapshot.price`，与生产一致）。
